# 001 — Gestion locale via un port applicatif

Statut : accepté dans le périmètre demandé.

Le binaire écoute sur loopback seulement. Le domaine expose une configuration validée et un port de gestion ; launchctl et les fichiers restent dans l'adapter macOS. HTTP ne construit jamais de commandes shell. Des doubles de test couvrent les mutations sans toucher aux LaunchAgents de l'utilisateur.

L'édition ajoute une route PUT absente de la liste initiale du plan. Stop utilise bootout pour respecter l'intention même avec KeepAlive. Les fonctionnalités multi-host et CPU/RAM du mock sont reportées selon le plan.
