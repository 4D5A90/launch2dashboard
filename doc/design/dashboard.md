# Dashboard

Mode: Operate

Autorité visuelle : ./dashboard-mockup.png fournie par l'utilisateur. Reproduction de son système, sans nouvelle direction artistique.

FIRST VIEWPORT: sidebar sombre étroite, titre Services avec recherche et Add Service, filtres d'état, liste centrale et panneau de détail droit. Violet pour sélection et action primaire, vert/gris/ambre/rouge pour états accompagnés de texte.

Les données sont réelles. Sur installation vide, la liste montre un état vide et une action de création. Les mesures CPU/RAM, hosts distants et onglets hors V1 ne sont pas reproduits. Sur mobile, colonnes empilées et sidebar compacte. Sélection service, actions et flux de logs sont les interactions centrales.

Build: directement dans le code à partir de la maquette déjà fournie ; pas de nouvelle image ni variante de design nécessaire.
